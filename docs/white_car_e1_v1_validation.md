# vggt-gen-v1 白车 E1 验证

2026-10-28 在 NVIDIA RTX A6000 上实际运行，Python 3.12.13、PyTorch
2.11.0+cu128、CUDA 12.8、gsplat 1.4.0。

固定的旧生成 PNG、掩码、相机和点云通过 204 个文件的 SHA-256 校验。
新封装从 21,112 个初始点重新训练 49,375 步，实际耗时约 20.4 分钟。
真实留出图不参与训练，评估和环绕视频使用旧实验相同的相机。

| 指标 | 原 E1 | 本次复现 | 差值 |
| --- | ---: | ---: | ---: |
| 训练前景 PSNR 中位数 | 24.3939 dB | 24.2480 dB | -0.1459 dB |
| 训练轮廓 IoU 中位数 | 0.90585 | 0.90367 | -0.00218 |
| 训练轮廓外 opacity / mask 面积 | 0.10322 | 0.10303 | -0.00018 |
| 16 张真实留出图 PSNR 中位数 | 17.7400 dB | 17.7498 dB | +0.0098 dB |
| 真实留出图轮廓 IoU 中位数 | 0.88703 | 0.88629 | -0.00074 |
| 真实留出图轮廓外 opacity / mask 面积 | 0.10885 | 0.10920 | +0.00035 |
| 最终高斯数 | 77,270 | 76,451 | -819 |

全部六项质量检查通过预先记录的容差：PSNR ±0.5 dB、IoU ±0.02、
轮廓外 opacity ±0.03。此结果复现了旧 E1 的指标范围，不是位级一致的训练结果。

另用仓库生成入口、固定旧六图及源/目标相机、50 步、seed 20261030
重新生成了 80 帧。与固定旧 PNG 比较，全图 PSNR 中位数 49.0943 dB，
范围 46.3106–52.0979 dB；80 帧都存在像素差异。因此严格 E1 复现仍使用
固定 PNG 和对应旧掩码，不声称已经用这批新生成图重新分割并训练 E1。
`--generated-frames` 的像素一致性检查会如实报出差异并拒绝混用掩码。

CPU 测试 37 项通过；wheel 构建通过，检查包含 `gen_pro`、E1 配置和基准模块。
机器可读指标和运行范围见 [white_car_e1_v1_validation.json](white_car_e1_v1_validation.json)。

本版本保留工作区已有的参考图旋转重投影、手动参考顺序、点云中心再次瞄准、
旧目标相机的相似变换映射及初始化侧车修复。这些视频预处理功能与固定旧 E1
验收入口分开，不能用固定输入通过验收来宣称任意视频流程已经复现旧实验。

复现入口与命令见 [白车说明](../examples/white_car/README.md)。
